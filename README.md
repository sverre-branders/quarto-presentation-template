# Quarto presentation template

A [Quarto](https://quarto.org/) [reveal.js](https://revealjs.com/)
presentation managed with [Pixi](https://pixi.sh/).

## Install
> [!NOTE]
> **Dependencies:** `git` `conda`

```bash
pixi install
```

## Usage

1. Configure the presentation metadata in `_quarto.yaml`
2. Add presentation content in `slides/content.qmd`
3. View the presentation

```bash
pixi run view
```
